# Legacy SHTENCO compressor inventory

The V4 work was assembled after locating these prior project families in the user's archive library:

- EGD-256 / EML Graal Dictionary;
- SABF-X / BLOCK_FAST;
- HACE-X / HyperCompressor;
- TSC-X / TurboSpatial;
- AMCE-100X / UltraCompress100X;
- Graal AI Storage;
- DeepCompress Spatial;
- SLOTA v2 and v3 combinatorial;
- Production BIP39 Compressor;
- SHTENCO BIP39 Final;
- standard wrapper engines for 7ZIP, LZMA9, LZ77, ZSTD and Brotli;
- the extended 23-engine and 35-profile tournament generations.

V4 does not pretend that differently named parameter profiles are mathematically independent codecs. The principal report therefore exposes seven comparable rows, while the complete diagnostic table retains all 35 reversible profiles.
