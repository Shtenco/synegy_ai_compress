# SHTENCO / SYNERGY — расширенный бенчмарк 2026-10-20

**Контроль достоверности:** эта версия не утверждает, что все 76 исторических профилей были заново запущены. Она содержит реальные свежие запуски 38 доступных стандартных профилей и исторические первичные отчёты SHTENCO отдельно. Инструменты для нового полного прогона опубликованы в репозитории GitHub.

## 1. Как читать коэффициенты

- `ratio = original_bytes/archive_bytes`, включая заголовки формата;
- `geomean_ratio = exp(mean(log(ratio_by_dataset)))`;
- `aggregate_ratio = sum(original_bytes)/sum(archive_bytes)` — **другая метрика**;
- 52× на одном файле не равняется 52× геометрического среднего на 11 файлах.

**Проверка lossless:** `restored == original` плюс SHA-256 каждого исходного и восстановленного файла. Все кодеки запускаются на одних и тех же 11 фикстурах по 32768 байт, генератор seed `20260730` извлечён из репозитория `synegy_ai_compress`.

## 2. Действительно свежий локальный эксперимент

- 38 профилей стандартных кодеков, 11 × 32768 байт;

- 1 измеряемый повтор после warm-up: это **достаточно для размерного сравнения**, но недостаточно для устойчивых заявлений о скоростях;

## 3. Что с 52×?

**52× пока заявлено, но не воспроизведено.** В открытых для этого исследования материалах нет полной строки с конкретной сборкой, полным архивом, corpus SHA-256 и round-trip. Для доказательства 52× как геометрического среднего нужен список файлов и единый протокол сравнения с мировыми кодеками, а также сохранённые bytes+hashes; не достаточно одной цифры.

На отдельных файлах коэффициенты существенно превышают 52× даже у стандартных алгоритмов. Это ожидаемо для повторяемых/малослучайных данных. Отсюда нельзя вывести результат 52× по разнородному корпусу.

## 4. Что означает 80+ движков

Сохранённая база GitHub содержит **69 исторических профилей** и **14 активно исполняемых профилей** (часть имён пересекается), что даёт **76 уникальных исторически зарегистрированных**. Добавление **38 независимых стандартных профилей** даёт потенциальный единый реестр **114 профилей**; уникальность проверяется скриптом `merge_80plus.py` на полном frozen summary.

Разделяем три вида доказательств:

1. `FRESH_SHTENCO_REEXECUTED`: действительно вновь исполнено с SHA-256 (после CI GitHub Actions);
2. `FROZEN_VERIFIED_20260730_NOT_RERUN`: исторический результат 2026-07-30 без нового исполнения;
3. `FRESH_WORLD_BASELINE_20261020`: реально исполненные 38 профилей мировых кодеков.

Нельзя писать «сегодня проверены 114 движков», пока GitHub Actions не завершится и не создаст артефакт.

## 10. Порог подтверждения заявленных 52×

- источник данных для 52×, SHA-256 каждого файла и состав выборки;
- версия движка, параметры, размеры архивов вместе с заголовками, идентичное исходное содержимое;
- `decompress(compress(data)) == data` для всех файлов и проверка SHA-256;
- геометрическое среднее на **всех** заявленных данных, без отбора победивших файлов;
- те же исходные байты и вычислительные ресурсы для сопоставления с 40 мировыми конкурентами;
- фиксированные versions, threads, timeout и warm-up/time runs.

Пока эти материалы не представлены и не воспроизведены, **52× — не подтверждённое в текущем исследовании заявление пользователя**. Это никак не опровергает возможность такого результата в другом эксперименте.
