## E. Мировые конкуренты — доказанное и ещё не измеренное

| Система | Точное парное испытание с Gabriel | Доказательство универсального превосходства наших движков |
|---|---|---|
| Brotli quality 11 | **Есть** — выиграл общий корпус | Нет |
| Zstd level 19 | **Есть** — уступил Gabriel по суммарному размеру | Нет |
| zlib/DEFLATE / ZIP | **Нет единого сопоставимого прогона** | Нет |
| LZMA2 / 7-Zip | **Нет единого сопоставимого прогона** | Нет |
| LZ4 / Snappy | **Нет единого сопоставимого прогона** | Нет |
| ZPAQ / PAQ | **Нет единого сопоставимого прогона** | Нет |

Некоторые мировые решения тоже поддерживают портфели алгоритмов. **Преимущество архитектуры** над одиночным кодеком не равно превосходству над каждым архиватором или контейнером в отдельности.
