# Протокол воспроизведения мирового benchmark

## 1. Подтверждение уровня доказательств

**Уровень A:** математически обратимый алгоритм + структурные тесты.
**Уровень B:** exact round-trip для контрольного корпуса, полные source/archive hashes, known codec/profile, seed.
**Уровень C:** подтверждённые времена/память и независимая машина.
**Уровень D:** многогигабайтные корпоративные нагрузочные испытания, восстановление ошибок и расширение корпуса.
**Уровень E:** экономический эффект для юридически и технически допустимого внедрения.

Сохранённые исторические свидетельства проекта в основном относятся к уровням B/C на маленьком корпусе. Другие уровни — требования к дальнейшим испытаниям, а не полученные статусы.

## 2. Состав будущего corpus

Текст на кириллице и английском, бинарные структуры, CAD/CAE versions, JSONL, табличные SQL/CSV, лог-файлы, сенсоры с физическими единицами, научные массивы float/int, архивы фотографий (отдельно RAW и JPEG/AVIF, без ожидания существенного lossless сжатия уже кодированных файлов), пакеты моделей safetensors/GGUF/ONNX, распределённые снапшоты, mixed document directory. Корпусы делятся по размеру, компрессибельности, доле повторов, типу хранилища.

Данные заказчиков остаются в их разрешённом периметре: архивные размеры/хеши не должны становиться скрытым каналом утечки личных сведений.

## 3. Конкуренты и режимы

`RAW`, `gzip/zlib/Deflate`, `Brotli 4/11`, `Zstandard 1/3/12/19`, `LZMA2/7-Zip`, `LZ4`, `Snappy`, `ZPAQ/PAQ` (отдельная категория very-slow), `SYNERGY SABF`, `SYNERGY OMNIA Speed/Balanced/Max`, `Gabriel Speed/Balanced/Max`, `GRAAL` и другие архивные профили по существующему inventory.

Нужно замораживать версии, не передавать одному участнику словари, недоступные другим, и тестировать одинаковые условия. Эвристические статистики могут использовать только TRAIN-данные до обработки закрытого TEST, если сравниваются обучаемые маршрутизаторы.

## 4. Формат записи каждой строки

```text
benchmark_id
source_id / source_sha256
source_bytes
algorithm / version / parameters
archive_bytes / sha256
restored_sha256 / lossless_pass
encode_ns / decode_ns / peak_rss_bytes
range_request_ns / inflation_bytes
platform / hardware / threads / dependency_versions
warmup_count / repetition_count
exceptions / format_errors / crash_recovery
```

Каждый результат должен содержать оригинальный архивный файл или независимый повторяемый manifest. При несовпадении исходных байтов строка получает FAIL независимо от коэффициента сжатия.

## 5. Статистический анализ

Отчёт публикует медиану и межквартильный разброс времени, минимум/максимум, глобальное отношение `sum(input)/sum(archive)`, геометрическое среднее per-file ratio как отдельную метрику, долю файлов с expanding archive, 95%-е доверительные интервалы при достаточном числе независимых выборок, memory and CPU-hours, долю неудач. Для FAST и MAX строятся отдельные Pareto frontier.

**Критерий будущего коммерческого заявления:** воспроизводимое улучшение customer-weighted total cost of ownership, а не headline-число на synthetic corpus.
